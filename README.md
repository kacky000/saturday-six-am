# Saturday Six A.M.

An entry for [Snooze Button Roast](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6) on make.fun.

`main.ts` writes one roast to `/output/entry.txt`, for an alarm clock with less respect for weekends than a manager.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
